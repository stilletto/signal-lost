# Signal Lost

A mobile-first FPV combat-drone simulator. [Play in your browser](https://stilletto.github.io/signal-lost/), [download Android v239 with FPS](https://stilletto.github.io/signal-lost/signal-lost.apk), or [download HEAVY v239 with FPS](https://stilletto.github.io/signal-lost/signal-lost-heavy-fps.apk).

This batch brings photographed soil, weathered wreck steel and timber, compact terrain buffers, retained tree density with fewer submissions, and genuinely below-grade connected trenches/dugouts to the player builds. The ground mesh and collision open around the positions; existing shelter AI follows their communication trench.

The regular ARM64 APK opens the mission menu. HEAVY opens The Third Knock immediately with three aircraft, with reserves following at 15 / 60 metres. Both retain their package IDs, signing certificate and career format; neither bakes in a fresh-profile reset, synthetic pilot, timed exit or free operator purchase. Both have the existing drone artwork and FPS display. Each download is 89.9 MiB.

Web runs the ordinary menu, fitting and live FPV flow. A disposable local harness using the same exported JS/WASM/PCK physically completes the three-aircraft combat, reserve takeover and dugout entry with three stars. The exported Android game resources also complete that route on desktop Compatibility. Android engine/device acceptance remains separate: the shared Samsung was neither installed nor launched in this batch, and stable handset 30 FPS remains open. Heavy geometry still exceeds the mobile budget. The old and new mobile texture packs also reproduce a desktop-Vulkan atlas-readback limitation, recorded in the source checkpoint rather than counted as a clean runtime pass.

The compiled single-thread Web build and both debug APKs come from source 91eaf5c07ac6af14c85cbceaea1b1ce131ad65be, produced with Godot 4.7.1. The 726 frozen source/test/tool files match the full 1,831-test and 60-scenario smoke gates. build.json identifies the downloadable hashes and runtime/device boundaries. [Source and development evidence](https://github.com/stilletto/signal-lost-source).

Third-party art comes from Kenney, Quaternius and Poly Haven; geographic features from OpenStreetMap contributors and NASA SRTM. Gun recordings come from the CC0 Free Firearm Sound Library and credited public-domain DVIDS footage; [sources, edits and limitations](https://github.com/stilletto/signal-lost-source/blob/91eaf5c07ac6af14c85cbceaea1b1ce131ad65be/assets/audio/reports/README.md).
