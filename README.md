# Signal Lost

A mobile-first FPV combat-drone simulator. [Play in your browser](https://stilletto.github.io/signal-lost/), [download Android v241 with FPS](https://stilletto.github.io/signal-lost/signal-lost.apk), or [download HEAVY v241 with FPS](https://stilletto.github.io/signal-lost/signal-lost-heavy-fps.apk).

This batch brings revetted below-grade trenches, authored soil and timber, clearer rifle/MG silhouettes made with the existing Blender pipeline, per-round automatic-fire reports without the duplicated near-pass hiss, and the existing soldier LOD adjustment. Wall-frame/census diagnostics now cover the complete sortie. The weapons retain shared materials, grip and thermal paint; their heavy-route geometry cost is about 0.3%, with unchanged submissions.

The regular ARM64 APK opens the mission menu. HEAVY opens The Third Knock immediately with three aircraft, with reserves following at 15 / 60 metres. Both retain their package IDs, signing certificate and career format; neither bakes in a fresh-profile reset, synthetic pilot, timed exit or free operator purchase. Both have the existing drone artwork and FPS display. Normal / heavy downloads are 90.1 / 90.1 MiB.

Web runs the ordinary menu, fitting and live FPV flow. A disposable local harness using the same exported JS/WASM/PCK physically completes the three-aircraft combat, reserve takeover and dugout entry with three stars. The exported Android game resources also complete that route on desktop Compatibility. Android engine/device acceptance remains separate: the shared Samsung was neither installed nor launched in this batch, and stable handset 30 FPS remains open. Heavy geometry still exceeds the mobile budget. The previously recorded desktop-Vulkan mobile-texture atlas limitation is not a clean runtime pass. Local in-app-browser timing remains a failed boundary, recorded separately from functional completion; desktop timing does not establish handset 30 FPS.

The compiled single-thread Web build and both debug APKs come from source ccd2a7ae4f18e802dbe918aa475f00c8b9ee8f77, produced with Godot 4.7.1. The 733 frozen source/test/tool/project and named asset inputs match the full 1,839-test and 60-scenario smoke gates. build.json identifies the downloadable hashes and runtime/device boundaries. [Source and development evidence](https://github.com/stilletto/signal-lost-source).

Third-party art comes from Kenney, Quaternius and Poly Haven; geographic features from OpenStreetMap contributors and NASA SRTM. Gun recordings come from the CC0 Free Firearm Sound Library and credited public-domain DVIDS footage; [sources, edits and limitations](https://github.com/stilletto/signal-lost-source/blob/ccd2a7ae4f18e802dbe918aa475f00c8b9ee8f77/assets/audio/reports/README.md).
