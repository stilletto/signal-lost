# Signal Lost

A mobile-first FPV combat-drone simulator. [Android v250 with FPS](https://stilletto.github.io/signal-lost/signal-lost.apk), [HEAVY v250 with FPS](https://stilletto.github.io/signal-lost/signal-lost-heavy-fps.apk), or [play the retained Web v246](https://stilletto.github.io/signal-lost/).

COUNT THE ENGINES is a new Kestrel night Mantis sortie at 1,200 points: identify the real gun truck through thermal, destroy it and recover the aircraft; a supply truck is an optional third star. Existing progression, rewards, stores and recovery remain canonical. The thermal sight now preserves the soft coverage of casualty and armour marks. The existing loading preflight prepares their actual material layouts before combat. Source Mobile repeats add no new first-impact pipelines; this does not establish handset FPS, and heavy geometry remains over budget.
