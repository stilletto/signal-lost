# Signal Lost

A mobile-first FPV combat-drone simulator. [Play in your browser](https://stilletto.github.io/signal-lost/), [download Android v246 with FPS](https://stilletto.github.io/signal-lost/signal-lost.apk), or [download HEAVY v246 with FPS](https://stilletto.github.io/signal-lost/signal-lost-heavy-fps.apk).

Fourteen filled cloth sacks now sit visibly in front of the dugout lining, using the existing canvas palette and physical Mound owner. Offset courses retain the 2.6 metre door and existing terrain cut, floor, path and timber. Sacks add 544 triangles per position and one material surface, with no new texture, material instance or node. The FPS panel now reads actual callback intervals and current tree processing from the existing wall clock instead of clamped simulation delta; FPS-only builds do not collect profiler history. This corrects the instrument and makes no FPS improvement claim.

The regular ARM64 APK opens the mission menu. HEAVY opens The Third Knock immediately with three aircraft, with reserves following at 15 / 60 metres. Both retain their package IDs, signing certificate and career format; neither bakes in a fresh-profile reset, synthetic pilot, timed exit or free operator purchase. Both have the existing drone artwork and FPS display. Normal / heavy downloads are 90.1 / 90.1 MiB.

Web runs the ordinary menu, fitting and live FPV flow. A disposable local harness using the same exported JS/WASM/PCK physically completes the three-aircraft combat, reserve takeover and dugout entry with three stars. The exported Android game resources also complete that route on desktop Compatibility. Android engine/device acceptance remains separate: the shared Samsung was neither installed nor launched in this batch, and stable handset 30 FPS remains open. Heavy geometry still exceeds the mobile budget. The previously recorded desktop-Vulkan mobile-texture atlas limitation is not a clean runtime pass. Local visual/route captures use the existing 30 FPS cap around shared GPU work; their timings do not establish headroom or handset 30 FPS. In-app-browser GPU timing is unavailable; capped intervals do not certify device performance. Local in-app-browser timing remains FAIL: actual baseline/candidate callback medians are 1014.8 / 1015.8 ms. The corrected FPS panel reflects these intervals; the old simulation-delta display understated them. No new slowdown or root cause is inferred from these capped/shared-PC runs.

The compiled single-thread Web build and both debug APKs come from source dbd60a5367e50e481fec7289f2aa3e0844763b3c, produced with Godot 4.7.1. The 739 frozen source/test/tool/project and named asset inputs match the full 1,872-test and 60-scenario smoke gates. build.json identifies the downloadable hashes and runtime/device boundaries. [Source and development evidence](https://github.com/stilletto/signal-lost-source).

Third-party art comes from Kenney, Quaternius and Poly Haven; geographic features from OpenStreetMap contributors and NASA SRTM. Gun recordings come from the CC0 Free Firearm Sound Library and credited public-domain DVIDS footage; [sources, edits and limitations](https://github.com/stilletto/signal-lost-source/blob/dbd60a5367e50e481fec7289f2aa3e0844763b3c/assets/audio/reports/README.md).
